## 📖 Sobre o Projeto

Este repositório contém o código-fonte e a documentação de um sistema de cancela automática desenvolvido como projeto prático do curso Desenvolvimento De Sistemas no SENAI.
O objetivo foi criar um protótipo funcional capaz de automatizar a entrada e saída de veículos em um estacionamento, garantindo o controle de fluxo e o monitoramento em tempo real.
